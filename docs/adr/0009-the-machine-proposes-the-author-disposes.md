# The machine proposes, the Author disposes

dendrograph is confident about what it observed and deferential about what it
interpreted. Anything inferred rather than measured is offered as a suggestion for the
Author to confirm, never written into the graph unilaterally.

## Consequences

This is one principle applied in many places, and it is the reason each of these looks
the way it does: pruning lists candidates but never deletes; Artifact identity can be
overridden by hand; Epoch Markers are declared, never inferred; AI-authorship is refused
outright as an undecidable judgment; `SUCCEEDS` edges are confirmed, not guessed;
Techniques carry a declared confidence and the evidence behind them.

The trade-off accepted is **coverage in exchange for trust**. A sparser graph the Author
believes is worth more than a dense one they have to second-guess — particularly here,
where the output gets repeated in interviews and on CVs, and a confident wrong edge
becomes a false claim about a person's own career. It is stated in the README as well as
here, because it settles future design arguments before they start.
